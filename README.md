# 3D Maze Renderer

A project that turns a maze stored in a json file into a 3D space you can walk around in and search for the exit.

## About the Project

The maze is generated by a recursive backtracker algorithm which you can find in my [maze-solving repo](https://github.com/IAmDaanE/maze-algorithms). The vizualization is done with `pygame` in python but the more intensive computations are done in C++. `Pybind11` links both together and creates a function the python script can import.

```cpp
//python compatible datatype
return py::array_t<float>(
        {static_cast<ssize_t>(800)},
        {sizeof(float)},
        raw_ptr,
        capsule
    );
```

The 3D graphics are calculated by raycasting. When the program is first started pygame projects all the walls onto a surface which is then turned into raw pixel values. When walking around the C++ script casts 800 rays to see how far the closest wall is in that direction. It sends that data to the pygame window that then draws a vertical line for all of these rays, the further the wall the smaller the line vertically.
```python
#the shorter the distance the smaller the gap between wall and ceiling
def get_dist_to_ceil(ray_length):
    wall_height = projection_constant / ray_length
    return round((600 - wall_height) / 2)
```
This method does limit to only looking horizontally and not vertically.

## Project Structure

```
3d-maze-renderer/
├── maze.json              # a json file storing pure booleans
├── main.py                # the entry point and visual logic
└── raycasting.cpp         # pure rgb value raycasting logic
```

## Controls

* **`Z` / `S`** – Move Forward / Backward (relative to camera viewpoint)
* **`Q` / `D`** – Strafe Left / Strafe Right
* **`Mouse`** – 360° Camera Look (The cursor is automatically hidden and captured)
* **`ESC`** – Release mouse control / Exit focus

## Getting Started

Requires:
* python 3.11+
* a C++ compiler supporting at least C++17 (e.g., GCC/MinGW via MSYS2 or MSVC)

Activate your virtual environment and install the required packages:

```bash
pip install -r requirements.txt
```

Compile the C++ extension module manually via PowerShell inside the project directory (enter your personal install locations):

```powershell
g++ -O3 -shared -std=c++17 -fPIC -I[python version include location] -I[pybind include location] -L[python libs location] raycasting.cpp -o raycasting.pyd -lpython311 -static -lstdc++ -lgcc -lwinpthread
```
*This generates `raycasting.pyd` directly inside your project directory, making it ready to be imported into your Python scripts.*
